## 一、LemonBCD介绍

**LemonBCD** 是一款面向普通电脑用户的**可视化、现代化、高安全性** Windows 启动项（BCD）管理工具。

当您的电脑安装了多个 Windows 系统（例如：Windows 11 + Windows 10，或者主系统 + 办公系统 + WinPE 维护系统）时，LemonBCD 提供多系统 Windows 启动菜单名称、默认系统、排列顺序、等待时间等功能的修改。**：
- **绿色单文件**：仅单个 `LemonBCD.exe`（约 200KB），无需安装、解压即用、不写任何系统注册表残留。
- **智能识别与物理定位**：自动识别电脑中安装的所有 Windows 系统，精准读取物理磁盘号、物理分区号、分区卷标与容量，杜绝“认错系统”的风险。
- **全多语言支持**：右上角支持一键秒切简中、繁中、英文、日文、韩文，无缝即时刷新。

## 二、四大核心安全措施（安全第一）

许多用户担心操作启动项会导致电脑蓝屏或丢失文件。LemonBCD 确立了严格的安全技术边界，可放心使用：

> [!IMPORTANT]
> ### 🛡️ 安全措施
> 1. **绝不删除操作系统**：本软件只修改引导菜单文本与顺序，**绝不会删除任何系统文件**。
> 2. **绝不格式化硬盘**：底层代码中没有任何磁盘擦除、分区抹除或格式化指令。
> 3. **绝不触碰个人数据**：不读取、不上传、不修改您的桌面、文档或任何私人文件。
> 4. **修改前自动创建备份**：每次您保存任何修改前，软件都会自动在同级 `Backup` 目录下**导出带时间戳的完整 BCD 镜像备份**，随时可一键无损复原！

## 三、快速上手：如何运行与切换语言

### 1. 以管理员身份运行
- 启动菜单属于 Windows 底层受保护区域，修改必须具备管理员权限。
- 将 `LemonBCD.exe` 放置在任意文件夹。
- **鼠标右键点击 `LemonBCD.exe` -> 选择“以管理员身份运行”**。

### 2. 切换软件显示语言
- 软件启动后会自动匹配系统语言；
- 也可以随时点击主界面右上角的 **`🌐 语言下拉框`**，自由切换为：
  - 简体中文
  - English
  - 繁體中文
  - 日本語
  - 한국어
- 点击即时全界面生效，无需重启软件。

## 四、核心功能操作指南

打开软件后，主界面上方是**系统卡片列表**，下方是**全局启动设置卡片**。

---

### 4.1 调整系统显示顺序（开机菜单排序）
开机时哪个系统排在第 1 位、第 2 位，、第 3 位，完全由自己决定：
- 在想要移动的系统卡片右侧，点击 **`⬆️`（上移）** 或 **`⬇️`（下移）** 箭头按钮；
- 系统列表会即时对调位置，并**自动静默保存**到系统引导区，界面下方状态栏显示绿色就绪提示。

---

### 4.2 设置默认启动系统
开机倒计时结束如果未按任何键，电脑将自动进入此默认系统：
- **方式一（最快）**：在系统卡片右侧直接点击 **`⭐ 设为默认`**，弹出确认框后点击确定即可。
- **方式二**：在下方的【全局启动设置】中，通过【默认启动系统】下拉菜单选取目标系统，再点击右下角 **【保存设置】**。

---

### 4.3 修改系统显示名称（重命名）
有些系统开机默认显示为复杂的英文（如 `"Windows 11 Professional"`），您可以将其改为亲切直观的名字（如 `"柠檬 的主系统"` 或 `"工作专用 Win10"`）：
1. 在目标系统卡片右侧点击 **`✏️ 重命名`**；
2. 在弹出的小窗口中输入新名称（最多支持 64 个字符，自动过滤双引号）；
3. 点击 **【确认修改】**，系统列表立刻更新。

---

### 4.4 设置开机等待倒计时（秒数）
控制开机菜单在屏幕上停留多久的按键选择：
1. 滚动到界面下方的【全局启动设置】区域；
2. 在【启动菜单等待时间】下拉框中选择快捷预设：
   - **0 秒**：完全不显示开机等待菜单，通电后直接秒进默认系统；
   - **3 秒 / 5 秒**：快速开机；
   - **10 秒 / 30 秒**：标准留空时间，方便看清系统选项；
   - **自定义秒数...**：支持输入 0 到 999 之间的任意整数秒数。
3. 点击右下角 **【保存设置】** 即可。

---

### 4.5 选择开机菜单风格（消除多系统黑屏二次重启）
微软 Windows 提供了两种截然不同的启动菜单视觉风格：

| 菜单风格 | 外观特点 | 运行机制与优势 | 推荐人群 |
| :--- | :--- | :--- | :--- |
| **标准现代风格** | 蓝色图形背景，支持鼠标点击与触控屏 | 界面现代美观，内建故障排查图形化高级工具 | 绝大多数单系统或普通 Win10/Win11 用户 |
| **旧版怀旧风格** | 经典的黑底白字传统启动文本菜单 | 由主板引导器直接调用，轻量极速，**彻底解决多系统切换时电脑先黑屏重启一次的烦恼** | 追求极速开机、或经常在双系统间切换的用户 |

> [!TIP]
> **关于“应用范围”的强烈建议**：
> 在风格下方提供应用范围选项，强烈建议保持勾选 **【应用于所有已发现的系统（推荐）】**。统一所有系统的开机风格后，无论进入哪个系统，都能享受到完全一致的稳定开机体验。

---

### 4.6 设置启动环境语言
用于配置开机引导菜单以及 Windows 蓝屏/恢复环境时的文本显示语言：
- 支持选择：简体中文、English、繁體中文、日本語、한국어；
- 在全局设置的【启动环境语言】下拉菜单中选取后，点击 **【保存设置】** 即可。

---

### 4.7 一键安全备份与配置恢复
LemonBCD 拥有完整的备份与历史还原功能：
1. 点击主界面右上角的 **`🛡️ 备份与恢复`** 按钮；
2. 在弹出的管理窗口中：
   - **手动创建备份**：点击【立即备份当前配置】，秒级生成一个独立的 `.bcd` 备份快照；
   - **还原旧配置**：在下方历史备份列表中，点击对应记录右侧的【恢复此备份】，二次确认后电脑启动菜单立即精准复原至该时刻；
   - **清理历史备份**：点击备份记录右侧的“垃圾桶”图标可删除单条旧备份；或勾选后点击【删除所选】批量清理。软件会自动清除非托管事务日志文件，保持磁盘干净整洁。

## 五、常见问题解答 (FAQ)

### Q1：为什么软件显示的盘符，和我当前在“此电脑”里看到的不一样？
> **解答**：这是 Windows 多系统的正常机制，并非识别错误！  
> Windows 采用**相对盘符机制**：任何一个 Windows 系统在启动后，都会把“当前运行的自己”挂载为 `C 盘`，而把其他处于休眠状态的 Windows 分区往后排为 `D 盘`、`E 盘`。  
> **正确辨别方式**：LemonBCD 在卡片上不仅显示盘符，还清晰标明了**物理磁盘号、物理分区号、分区卷标与真实容量**（例如：`磁盘 0 分区 5 [Work] (200 GB)`）。请认准物理分区和卷标，就不会认错！

---

### Q2：我希望电脑通电后以最快速度直接进入主力系统，该怎么设置？
> **解答**：
> 1. 将主力系统设为【默认启动系统】；
> 2. 将【启动菜单等待时间】设置为 **0 秒**；
> 3. 点击【保存设置】。  
> 以后开机电脑将直接秒进系统，不再停留等待。若某天偶尔想进入备用系统，只需在开机亮屏时狂按主板临时启动热键（如微星/技嘉/联想 `F12`、华硕 `F8`）即可。

---

### Q3：为什么我在双系统切换时，电脑经常黑屏重启一次才进系统？
> **解答**：
> 这是因为您的默认系统开启了《标准现代风格》（蓝色图形菜单）。开机时电脑会先预加载默认系统的内核来绘制蓝色图形；当您在图形菜单里选择了另一个系统时，电脑不得不完全关闭当前内核并重新冷重启一次。  
> **解决方案**：在 LemonBCD 中将【启动菜单模式】切换为 **《旧版怀旧风格》（黑底白字传统启动菜单）**，勾选“应用于所有已发现系统”，点击保存。以后每次切换系统都将**直接秒进，彻底消除二次重启**！

---

### Q4：为什么我修改了“启动环境语言”为英文，开机时蓝色菜单还是中文？
> **解答**：
> - 在安装了 Windows 中文版和选择了《标准现代风格》下，蓝色图形菜单由当前默认 Windows 内核绘制。若当前系统内部没有安装完整的英文系统语言包，内核会自动退回系统主语言（中文）；
> - 若需要 100% 显示纯正外语菜单，需切换为《旧版怀旧风格》，或者安装 Windows 英文版。

---

### Q5：为什么双击运行软件时提示“拒绝访问”或没有管理员权限？
> **解答**：
> Windows 启动配置数据（BCD）受系统核心保护，必须以管理员权限读写。请在 `LemonBCD.exe` 上点击鼠标右键，选择 **“以管理员身份运行”** 即可正常使用。

## 六、注意事项与便携使用

1. **便携即用**：本程序为完全绿色独立的单文件工具，可以将 `LemonBCD.exe` 复制到 U 盘、移动硬盘或 WinPE 系统维护盘中，随插随用。
2. **系统环境兼容**：基于 `.NET Framework 4.8` 开发，Windows 10（1903 及以上版本）与 Windows 11 全系列已原生内置该框架，双击直接运行，无需下载安装任何补丁包。
3. **安全备份目录**：每次修改配置时，程序同级目录下会自动生成 `Backup/` 文件夹。请妥善保留该文件夹，这是随时找回历史引导配置的安全盾牌。
